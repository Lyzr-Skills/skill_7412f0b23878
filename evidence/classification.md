# Classification Taxonomy

All findings must be classified into one of the following confidence tiers:

1. **verified**: Confirmed by multiple high-weight first-party sources.
2. **observed**: Clear patterns detected in external communities or limited first-party pools.
3. **inferred**: Logical deduction backed by observed signals, but lacking explicit quotes.
4. **hypothesis**: Plausible guess based on context constraints. Lacks direct signals.
5. **unknown**: Explicitly flagged when data points are completely missing.
6. **contradictory**: Opposing evidence elements observed at similar weight.
